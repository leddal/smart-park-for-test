# 生产要求与降级说明

## 定位与分类

本版是单公园桌面演示与真实业务管理项目。数据落库、预约规则、告警到事件/任务的状态管理属于实际业务；输入设备和外部回执属于简化模拟。没有后续真实硬件接入目标，不把生产说明当作已接通能力。不交付移动端、生产部署或高可用集群。

界面静态主题位于 `frontend/src/content/productionHints.ts`，由 `ProductionHint.vue` 展示“当前实现、降级原因、按照正常生产要求应该怎样做、本版是否支持”。内部后台帮助入口 `/admin/help/production/:topic` 使用相同受控文本；不插入不可信 HTML，不依赖访问外部网站。

## 五类平台分别说明

下表的数据范围是需求/生产对应关系，不是本版已实现的平台专属字段映射或业务快照。手工同步只记录四种共享业务类型和操作者；自动事件/办结/整改只记录关联 ID，生成不指定外部平台的“通用事件模拟”回执，均不发送外网。

| 原需求平台 | 需求/生产对应数据范围 | 生产专属条件 | 不能声称的能力 |
|---|---|---|---|
| 上海市智慧公园综合管理平台 | 公园概况、模拟客流、事件状态 | 市级公园标识、官方报送频率/字段、身份授权、环境准入 | 已真实报送市平台 |
| 区城运汇治理系统 | 事件分发、办结与整改反馈 | 官方事件目录/编码、责任机构、闭环状态、回调/幂等、跨部门权限 | 官方事件工单已派发/接收 |
| 徐汇区视觉中枢平台 | 摄像头资源元数据 | 视频平台资源编码、GB28181/RTSP、媒体分发权限、录像/网络能力 | 视频已传输/联通视觉中枢 |
| 徐汇区绿化动态管理信息系统 | 植物台账、养护与整改记录 | 官方绿化资产字典、坐标/种类/养护字段、变更规则 | 官方植物库已更新 |
| “随申码”运行管理平台 | 本版独立资产物码公开介绍示例 | 官方码制与主体授权、认证/实名规则、合规接口和隐私审查 | 已获得随申码认证、实名或官方二维码 |

示例资产二维码是本应用 URL，不是官方随申码，不用于扫码打卡。后台可手工生成资产、物码、客流和视频元数据的模拟记录。事件创建、办结与整改反馈通过业务事务生成 outbox。RabbitMQ 真实传输只发生在本地容器网络；发布和消费分开记录，已确认发布不等于平台成功。连续发布失败或模拟消费失败各有 5 次上限；消费耗尽进入死信，失败消息人工重放递增代次并保留旧日志。回执与去重进度同库提交后才 ACK；本地故障恢复不证明真实第三方可靠性，亦不承诺代理卷丢失后的自动恢复或生产高可用。

## 指标公式与数据解释

生态综合分：

```text
A = clamp(100 × (1 − PM2.5 / 150), 0, 100)       PM2.5：μg/m³
N = clamp(100 × (1 − max(dB − 35, 0) / 50), 0, 100)
W = clamp(100 × DO / 8, 0, 100)                 DO：mg/L
E = 0.4A + 0.3N + 0.3W                         保留一位小数
```

以各设备最新有效样本再按指标求均值，必要指标缺失或超 10 分钟不计算综合分，不补零/不改权重。来源标签与采集时间应保留；无实际传感器输入。

植物碳储量：`B=0.1×D²×H kg`，`C=B×0.5×44/12 kg CO₂ 当量`。缺少有效 D/H 不估算，总计需区分有效/缺失记录。系数仅供演示，不含树种差异、根系、年龄与增长。

游客量仅来自模拟进出计数，不是视觉识别或人脸处理。计数不能为负、幂等重试不重复计数；“采样新鲜”只表示演示数据时间，不能称实际设备健康。

## 导入和照片边界

- GeoJSON 与 CSV 只处理轻量文件；预览再确认，编码/坐标/几何等错误不能当导入成功。园路连通只依赖录入节点，无路径不能用直线替代。
- DOM 必须由用户提供已配准范围；合成 `park-dom.png` 不是航拍影像、实际测绘成果或经过地理校准的数据。
- `broadcast.wav` 是本地产生的短音频提示音，不是紧急广播内容，播放必须用户点击。
- 图片签名与大小校验不是恶意媒体深度扫描；本版不保证删除 EXIF。正常生产应增加病毒/内容扫描、解码检查、EXIF 脱敏、对象存储、签名访问、生命周期管理和容量限制。
- 内部照片不是静态公开目录；照片读取仍需角色/任务归属检查。游客物码页面仅含公开介绍，不含维修备注、照片、人员信息或内部事件。

## 正常上线要求（不在本版交付）

TLS/反向代理信任设置、Secure Cookie、独立高强度凭据、禁用示例账号/模拟、管理员初次配置流程、数据库最小权限、备份及定期恢复演练、对象存储/上传扫描、日志脱敏、审计留存、限流容量验证、个人信息最小化、告警运维与容灾。

本机默认仅 loopback 开放不等于生产安全认证。所有实际上线措施均需部署设计与安全评估，不因存在 Identity、防伪或业务测试就承诺通过生产安全验收。
